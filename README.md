# 📂 Backend - Gestion des Catégories  

Ce projet est une API backend développée en **Node.js** avec **Express.js** permettant de gérer un système de **catégories hiérarchiques**. Il permet de :  
- **Créer** des catégories  
- **Définir une hiérarchie** (catégories parentes/enfants)  
- **Filtrer** les catégories selon la date de création ou leur statut de parent  

## 🛠 Technologies utilisées  
- **Node.js** + **Express.js**  
- **MongoDB** (ou une base de données NoSQL)  
- **Docker** (optionnel)  

## 🚀 Lancement  
1. Installer les dépendances :  
   npm install
   
3. Démarrer le serveur :  
   npm start

## 📝 Test de l'API  
Tu peux tester l’API via :  
- **Postman**  
- Un **frontend** qui consomme l'API
